एडमिन प्रवेश

इसे केवल पहली बार करना है। GitHub की एक चाबी (access token) बनाकर यहाँ डालें — फिर यह डिवाइस याद रखेगा, दोबारा पासवर्ड नहीं माँगेगा।

1. github.com पर लॉगिन करें
2. Settings → Developer settings → Personal access tokens → Fine-grained tokens
3. Generate new token
4. Repository access में अपना exhibition repo चुनें
5. Permissions में "Contents" को Read and write करें
6. Generate token दबाएँ और उसे कॉपी करके नीचे डालें
